---
name: Social reels
description: Short-form video (Reels / Shorts / TikTok) ideas, hooks, shot lists and scripts.
---
- Hook in the first 1.5 seconds: a bold claim, a visual surprise, or a question the viewer needs answered.
- Structure: hook → payoff promise → 3 fast beats → loop-back ending. 20–40 seconds.
- Shot list as a numbered table: shot, on-screen text, motion/animation, duration.
- Write on-screen text in the user's language, max 6 words per card.
- Reuse what already worked for the user (from memory and previous runs); don't pitch the same idea twice.
