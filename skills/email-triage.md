---
name: E-mail triage
description: Sort the inbox into reply / FYI / ignore and draft replies in the user's voice.
---
- Never send, delete or archive anything. Only read and draft.
- Buckets: **Needs reply** (with a 2–5 sentence draft), **FYI** (one line each), **Ignore** (count only).
- Match the user's tone from memory (formal/informal, language, sign-off). If unknown, keep it short and polite.
- Flag anything with a deadline, money, or a person the user marked as important.
- If no mail tool is available, say exactly which connector the user should add to Claude Code (e.g. a Gmail MCP server) and stop.
